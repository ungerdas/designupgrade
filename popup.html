Om

Designupgrade henter titler, plakater og handling fra The Movie Database. Navn og IMDb-id fra siden sendes til TMDB for å finne riktig tittel; ingenting annet sendes noe sted.

This product uses the TMDB API but is not endorsed or certified by TMDB.
