# Designupgrade

Små designjusteringer i Firefox. Torrentsiden får plakat, handling og sjangre fra TMDB, og torrentlistene får kortvisning med plakater og flagg for lyd og nordiske undertekster. Topp 10 får samme kortvisning, og hele siden kan få mørk modus (basert på tavi206 sitt tema). Alt kan skrus av med ett klikk.

## Installere

1. Last ned `designupgrade-….xpi` fra [siste utgivelse](https://github.com/ungerdas/designupgrade/releases/latest) og dra fila inn i Firefox (142 eller nyere, PC).
2. Hent en gratis API-nøkkel på [themoviedb.org](https://www.themoviedb.org/settings/api), klikk på D+-ikonet og lim den inn.

Utvidelsen kommer også på Firefox Add-ons, og da oppdateres den automatisk.

## Personvern

Tittel, år og IMDb-id sendes til The Movie Database for å finne riktig plakat og handling. Ingenting sendes til utvikleren, og det er ingen sporing.
